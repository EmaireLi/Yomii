# Yomii 项目总览

这份文档用于替代原来的项目计划、项目总结和需求分析，保留当前还需要的核心信息，去掉历史过程中的重复描述。

## 1. 项目定位

Yomii 是一个面向日语学习场景的桌面化学习应用，目标是把四条核心学习链路整合到同一套系统中：

- 搜索
- 背单词
- 测试
- AI 作文评测

项目同时支持：

- Web 前后端联调
- Electron 桌面运行
- 本地模型 + DeepSeek API 的混合作文评测方案

## 2. 当前架构

### 前端

- Vue 3
- TypeScript
- Element Plus
- Vite
- Electron

### 后端

- FastAPI
- SQLModel / SQLAlchemy
- JWT 认证

### 数据层

- SQLite：词典、词级、题库等静态数据
- MySQL：用户、收藏、学习进度、测试记录、作文记录、学习计划等行为数据

### AI 能力

- 本地评分模型：`Qwen/Qwen3-1.7B` 微调后部署
- 本地修订模型：`Qwen/Qwen3-1.7B` 微调后部署
- 在线补充：DeepSeek API

## 3. 功能范围

### 搜索

- 多字段查词
- 搜索历史
- 收藏联动

### 背单词

- 学习计划
- 间隔重复复习
- 掌握状态更新
- 薄弱项强化

### 测试

- 分级出题
- 测试记录
- 能力报告
- 趋势和建议

### 作文评测

- 提交作文
- 原文评分
- 修改建议
- 修订版本生成
- 历史记录与异步状态

## 4. 运行方式

### 轻量运行

- 前端 + 后端
- 作文模块可走 mock

### 完整运行

- 前端或 Electron
- 后端
- 本地评分模型
- 本地修订模型
- 可选 DeepSeek API

### 交付方式

- 轻度使用：直接使用 Release 桌面版
- 完整体验：拉源码、装依赖、启动全部服务

## 5. 关键设计

### 双数据库

- 把静态词典和用户行为数据拆开
- 便于更新词库，也便于管理用户侧数据

### 作文评测混合架构

- 本地模型优先
- DeepSeek 作为补充候选和兜底
- 候选结果复评后择优返回

### 训练与部署分离

- 训练阶段使用 LoRA / QLoRA
- 部署阶段使用合并后的独立模型
- 最终模型再做 `BNB 4-bit NF4` 量化

## 6. 当前状态

当前仓库已经具备课程项目交付所需的完整主链路：

- 前后端可运行
- 双数据库链路已接通
- 作文评测支持本地模型与 DeepSeek 混合策略
- Electron 桌面版本可打包发布

## 7. 非功能要求

- 页面和接口响应保持在可接受范围内
- 文档、接口和实现保持一致
- 本地运行链路尽量简化
- 模型服务异常时有兜底结果
- 用户数据仅保存必要学习信息
