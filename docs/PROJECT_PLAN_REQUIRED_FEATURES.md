# Yomii 功能清单（依据《项目计划书.docx》）

> 用途：后续开发任务对照清单（仅列“需要完成”的功能，不含测试数据）。

## 1. 核心功能模块

- [ ] **登录与认证（LoginView）**
  - [ ] 用户登录（用户名/邮箱 + 密码）
  - [ ] 用户注册（可选但建议实现）
  - [ ] 用户登出
  - [ ] 登录态校验（需要登录访问 or 游客访问策略）

- [ ] **首页（HomeView）**
  - [ ] 应用概览
  - [ ] 功能导航入口
  - [ ] 已登录用户个人中心入口

- [ ] **搜索功能（SearchView）**
  - [ ] 单词搜索
  - [ ] 搜索结果展示
  - [ ] 搜索历史记录

- [ ] **背诵功能（ReciteView）**
  - [ ] 背单词内容展示
  - [ ] 学习进度追踪

- [ ] **测试功能（TestView）**
  - [ ] 题目展示
  - [ ] 答题交互
  - [ ] 成绩统计

- [ ] **作文评测功能（EssayView）**
  - [ ] 作文编辑与提交
  - [ ] AI 智能评测反馈
  - [ ] 历史作文查看

## 2. AI 评测能力要求

- [ ] 语法检查评分
- [ ] 词汇使用评分
- [ ] 流畅度分析
- [ ] 内容质量评估

## 3. 非功能性要求（验收相关）

- [ ] 页面首屏加载时间 < 2 秒
- [ ] 搜索响应时间 < 500ms
- [ ] 支持现代主流浏览器
- [ ] 代码结构可扩展（便于后续功能迭代）

## 4. 交付与文档要求

- [ ] Yomii Web 可运行版本
- [ ] 前端构建产物（dist）
- [ ] Docker 镜像（可选）
- [ ] 用户使用手册
- [ ] 安装部署指南
- [ ] FAQ 文档
- [ ] 架构设计文档
- [ ] API 接口文档（与实现一致）
- [ ] 项目总结报告
