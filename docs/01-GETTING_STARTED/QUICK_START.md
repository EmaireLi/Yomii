# 🚀 快速开始指南

## 📱 应用导航

### 首页 (Home)
显示学习概览和统计数据
- **学习统计卡片**：总背词数、今日背词、连续天数等
- **团队信息**：开发小组成员名单
- **功能导航**：快速访问各功能模块

### 查词 (Search)
快速查询日语词汇
- **搜索框**：输入假名、汉字或中文
- **搜索历史**：快速重新搜索
- **收藏功能**：❤️ 保存喜欢的词汇
- **词汇详情**：释义、例句、标签等

### 背单词 (Recite)
高效的闪卡学习
- **翻转卡片**：点击或按 Space 查看释义
- **三级评价**：不认识 / 模糊 / 认识
- **进度追踪**：显示当前进度和总数
- **学习统计**：完成后显示掌握情况

### 能力测试 (Test)
评估日语水平
- **难度选择**：初级 / 中级 / 高级
- **实时计分**：显示答对题数
- **答案解析**：提供详细的解释
- **成绩报告**：个性化学习建议

## ⌨️ 快捷键

### 背单词模式
```
Space  →  翻转卡片显示释义
1      →  评价为"不认识"
2      →  评价为"模糊"  
3      →  评价为"认识"
```

### 其他
```
Enter  →  搜索框中提交搜索
```

## 💡 使用技巧

### 🔍 高效搜索
- **输入假名**：`べんきょう` → 查找"勉強"
- **输入汉字**：`勉強` → 快速查找
- **输入中文**：`学习` → 按释义搜索

### 📚 背单词技巧
1. 首先看词汇本身
2. 思考是否认识
3. 按 Space 查看释义
4. 诚实评价掌握程度
5. 系统自动记录进度

### 📊 跟踪进度
- **侧边栏**显示今日目标进度
- **首页**显示总体学习统计
- 数据自动保存到浏览器本地

## 💾 数据管理

### 自动保存
所有数据自动保存到浏览器 localStorage：
- 搜索历史
- 收藏词汇
- 学习进度
- 测试成绩

### 导出数据
侧边栏"快捷操作"中的"💾 导出数据"功能：
- 导出为 JSON 格式
- 包含完整的学习统计
- 可用于备份或转移

### 清空历史
侧边栏"快捷操作"中的"🗑️ 清空历史"功能：
- 清空搜索历史
- 不影响其他数据

## ❓ 常见问题

### Q: 数据会丢失吗？
A: 不会。数据保存在浏览器本地存储中，除非手动清除浏览器数据或使用无痕模式。

### Q: 可以在其他设备上使用吗？
A: 可以。使用"导出数据"功能备份当前设备数据，在新设备上导入即可（后续版本支持）。

### Q: 如何重置所有进度？
A: 使用"清空历史"功能，或手动清除浏览器缓存数据。

### Q: 为什么搜索不到词汇？
A: 检查拼写，尝试其他搜索方式（假名/汉字/中文）。当前测试库包含 10+ 常用词汇。

### Q: 测试题目会重复吗？
A: 当前题库包含多个题目，会随机出现。后续版本会增加更多题库。
